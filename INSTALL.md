# Installing Achievements Unlocked

## From the manifest URL (recommended)

1. In Foundry, open **Add-on Modules → Install Module**.
2. Paste into *Manifest URL*:
   ```
   https://github.com/m-andriiash/achievements-unlocked/releases/latest/download/module.json
   ```
3. Click **Install**, then enable *Achievements Unlocked* in your world's
   **Manage Modules**.

## Manually

1. Download `achievements-unlocked-<version>.zip` from the
   [releases page](https://github.com/m-andriiash/achievements-unlocked/releases).
2. Extract it to `<FoundryData>/Data/modules/achievements-unlocked/` so that
   `module.json` sits directly inside that folder.
3. Restart Foundry (or reload the setup screen) and enable the module.

## Requirements

- Foundry VTT 13 or newer (verified on 14). Any game system.
- Nothing else. Badge images can be any image Foundry can serve (PNG, JPG,
  WebP, SVG); use *Browse* in the achievement editor to upload one.
